## List
- 순차 리스트
- 동적 배열이라고도 불린다 - 밖에서 보기에 추가가 자유로워 보임
- 추가가 자유로운 배열 같다

- Count - 원소가 몇개인가
- Capacity - 원소의 개수와 상관없이 내부적인 배열의 크기가 몇개인가

- 접근(읽기) - O(1)
- 탐색 - O(n) - 순환해서 확인해야 함
- 삽입 : 맨 뒤 추가시 O(1), 중간 삽입시 한칸씩 미뤄야 하므로 O(n)
- 삭제 : 맨 뒤 삭제시 O(1), 중간 삽입시 한칸씩 당겨야 하므로 O(n)

- Generic을 적용해서 미리 구현해 놓은것 -> Generic Collection
- 자료구조의 구현체 -> Collection

## Count / Capacity

- 클래스인 리스트를 처음 5개로 할당하고 6개의 값을 추가했을때
-> 2배 크기인 배열이 생기고 이전배열에 있던값은 복사하고 6번째 값을 새로 추가
-> 이렇게 되면 O(n)이 된다
- 조심해서 사용해야 하고 크기를 정해서 사용하는 것이 좋다

## LinkedList

- 연결 리스트의 기본 단위 -> 노드
- 단일 연결 리스트 : 다음 노드만을 참조
- 이중 연결 리스트 : 이전 노드와 다음 노드를 참조
- 원형 연결 리스트 : 맨 뒤의 노드가 다시 첫번째 노드를 참조하여 원형형태
- 이중 원형 연결리스트 : 원형 연결에서 이전 노드도 참조

-> 다음 노드의 참조를 가지고 있다고 생각
-> 삽입 삭제가 효율적이다

## 시간복잡도

- 접근 : O(n)

- C# 제네릭 컬렉션은 이중 연결 리스트로 되어있다.



## Stack / Queue

## Stack (Last in First out)
- 선입 후출 로 작동한다.

- Peek : 맨 위에 값이 뭔지 '확인만' 해준다
- Pop : 값 빼기 데이터를 하나씩 '뽑아'온다
- Push : 값 넣기


## Queue (First in First out)
- 선입 선출 로 작동한다.

- Enqueue : 값 추가
- Dequeue : 값 들어간 순서로 뺴기
